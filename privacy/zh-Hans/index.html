Bestli 隐私政策

最后更新：2026年10月5日

Bestli 的运营者

Bestli 是 Zsolt Báthori 以个人身份使用的产品名称。它不是独立的公司或法律实体，也没有 CVR 编号。联系方式：bestli.app.team@outlook.com。

控制者与角色数据与用途共享保留您的权利联系

1. 控制者与角色

我，Zsolt Báthori，运营 Bestli，并决定如何使用个人数据来运行平台、管理账户、维护公开的商家资料和评价、提供支持、保障服务安全以及管理订阅。就这些活动而言，我是数据控制者。

当商家使用 Bestli 保存其客户的预约、联系方式、到访记录或备注时，由该商家决定为何需要这些记录，通常也由其担任这些记录的控制者。我按照商家的指示处理这些数据，以提供预约和管理工具。如对某次预约或某商家自身的记录有疑问，请先联系该商家。当我代表商家处理个人数据时，商家与我必须在这些数据被添加到 Bestli 之前签订书面数据处理协议。

2. 我使用哪些信息以及原因

所涉及的信息取决于您使用的功能。我使用这些信息来提供您请求的功能、保持 Bestli 正常安全运行并回复您。

信息用途及通常的法律依据
账户名称、电子邮件地址和登录信息创建并保护您的账户，提供您请求的服务（合同，GDPR 第 6(1)(b) 条）；保护服务免遭滥用（正当利益，第 6(1)(f) 条）。
商家名称、类别、地址、联系方式、服务、价格、营业时间和所选照片建立并展示您请求的商家资料，让客户能够找到并联系该商家（合同）。
预约、客户联系方式、商家备注、日程和收入记录提供预约和商家管理功能。对于商家的客户记录，通常由商家担任控制者，Bestli 按其指示处理。
评分、评价内容和可选照片展示您选择发布的评价并运营发现服务（服务合同以及您发布的选择）。查看商家资料的任何人都能看到公开评价。
反馈消息和可选附件阅读并回复您发送的反馈或支持请求。
推送通知的设备令牌将您开启的通知发送到您的设备。您可以在设备设置中关闭通知。
设备的大致位置（可选）在您开启该功能时对附近商家进行排序。按照应用当前的设计，此位置仅用于该排序；不会存储在您的 Bestli 账户中，也不会发送到 Bestli 的服务器。
订阅和付款状态管理商家订阅及相关记录。在 iPhone 或 iPad 应用中购买的订阅由 Apple 通过 App Store 销售并收费（App 内购买）；在 Android 和网页上由 Stripe 处理付款。我不会接收或存储您的完整卡号。
团队成员身份（如果商家将你添加为员工）商家邀请的电子邮件地址以及与你相关的预约，以便你查看和管理自己在该商家的预约（合同；商家的正当利益）。
提醒和其他通知预约提醒和更新、评价和再次预约提醒，以及你收藏的商家发布的临时空位（正当利益）。你可以在设备设置中关闭这些通知，或取消收藏某个商家以停止接收其公告。

当某项信息是提供您请求的功能所必需时，通常的依据是合同。我基于正当利益，将有限的信息用于服务安全和支持。位置信息为可选项，取决于您设备的授权。法律要求时我会保留信息。如果您不提供必需的账户信息，我可能无法创建账户或完成预约。

3. 公开信息

商家资料的目的就是被发现。商家自行选择公开哪些信息，例如名称、位置、服务、营业时间、照片和评价。任何使用"发现"或共享资料链接的人都可以看到这些信息。预约中的联系方式只会与处理该预约的商家共享，不属于公开资料的一部分。

拥有 Bestli 账户的商家员工可以看到与其相关的预约，包括顾客的姓名、电话号码和备注。

4. 服务提供商及其他接收方

  • Supabase 提供身份验证、数据库和文件存储服务。
  • Google 提供"使用 Google 登录"，并在 Android 应用中提供用于推送通知的 Firebase Cloud Messaging 以及用于地图和地址功能的 Google 地图。
  • Apple 提供"通过 Apple 登录"，并在 iPhone 和 iPad 应用中提供用于商家订阅的 App Store 和 App 内购买、推送通知（Apple Push Notification service）以及用于地图和地址功能的 Apple 地图。
  • Stripe 处理在 Android 或网页上进行的商家订阅付款，并提供其付款/客户门户。
  • Microsoft Outlook 提供支持电子邮件收件箱。
  • GitHub Pages 托管本公开信息网站，并可能在托管过程中处理基本的技术请求信息。
  • 商家会收到其处理在该商家预约所需的预约和客户信息。公开的资料和评价信息按上文所述可见。
  • Brevo 发送与账户相关的电子邮件，例如重置密码。
  • 商家添加法定节假日时，由 Nager.Date 提供节假日日期；请求仅包含国家和年份，以及设备的 IP 地址。
  • 收到反馈或举报时，ntfy 会向运营者发送内部提醒；提醒不包含个人数据。
  • 如果商家所有者或员工在日历应用中订阅自己的预约，该日历服务商会按其自身条款接收这些预约（顾客姓名、电话号码和服务）。

我不会出售个人信息，也不会将其用于广告。服务提供商可根据其自身条款以及（如适用）书面数据处理安排处理信息。

5. 跨境传输

部分服务提供商可能会在欧洲经济区以外（包括美国）处理信息。处理地点和传输机制取决于服务提供商和项目配置。当传输需要保障措施时，必须有合法机制作为依据，例如充分性认定或标准合同条款。如需了解适用于您数据的保障措施，请与我联系。

6. 信息保留期限

账户信息在账户有效期间保留。您可以在应用的"设置"中发起删除账户。删除会将账户和商家信息从在用服务中移除；有限的副本可能会暂时保留在服务提供商的备份或安全记录中，直至其正常保留周期结束。为履行法律义务、解决争议或保护服务，我可能会在必要期限内保留特定记录。在您的 Bestli 账户删除后，商家仍可为其自身的合法记录保留其控制的预约信息。

删除账户后，你即将到来的预约会被取消并通知相关商家；过去的预约按上文所述保留在商家处。商家被删除时，在该商家有即将到来预约的顾客会收到取消通知。过去的休息日会自动删除。

7. 您的选择和权利

您可以在"设置"中编辑或删除您的资料、服务和照片，删除账户，并在设备设置中关闭位置权限或通知。根据适用法律和具体情况，您还可以请求访问、更正、删除、限制处理或数据可携；反对基于正当利益的处理；并在以同意为依据时撤回同意。如需行使这些权利，请通过电子邮件与我联系。如果我是代表某商家处理信息，我可能需要将请求转交给该商家并协助其答复。

您可以向您居住或工作所在地的监管机构投诉。在丹麦，该机构为丹麦数据保护局（Datatilsynet）。

8. 安全

应用与其服务提供商之间传输的信息在传输过程中受 HTTPS/TLS 保护。我使用服务提供商的访问控制，并采取合理措施，将访问限制在运营 Bestli 所需的范围内。任何在线服务都无法保证绝对安全。

9. 儿童

Bestli 不面向 16 岁以下的任何人，且服务条款要求用户年满 16 岁。如果您认为有 16 岁以下的人创建了账户，请与我联系，以便我审核并在适当情况下将其删除。

10. 网站与变更

本静态信息网站的页面代码中目前没有任何广告或分析标签。但其托管方仍可能处理技术连接数据。当应用、服务提供商或法律要求发生变化时，我可能会更新本政策；上方日期显示最新修订。
