Bestli の使い方

最終更新日：2026年10月6日

Bestli は iPhone、iPad、Android で同じように使えます。下から目的を選んでください。お客様として予約する方と、事業者として予約を受ける方向けです。

お客様向け

1はじめに

  • Bestli をダウンロードし、Google、Apple、またはメールアドレスでサインインします。お客様は Bestli を常に無料で使えます。
  • 言語は 設定 → 環境設定 → 言語 で変更できます。
  • 名前と電話番号を 設定 → 自分の情報 に保存すると、予約のたびに自動入力されます。
↑ トップへ戻る

2お店を探す

  • 探す で、名前・サービス・カテゴリ・都市・国から検索できます。
  • 検索欄の横のフィルターボタンで絞り込み：カテゴリ、営業中、距離、オンラインか対面か、支払い方法、評価、価格。
  • マップ では同じお店がピンで表示されます。
  • ♥ をタップしてお店を保存すると、直前に空いた枠を知らせてもらえます。
↑ トップへ戻る

3予約する

  1. お店を開いて 今すぐ予約 をタップします。
  2. サービスを1つ以上選び、日付と空いている時間を選びます。埋まっている時間をタップするとキャンセル待ちに登録できます。
  3. 時間の下でスタッフを選ぶか、指定なし のままにします。
  4. 必要ならハウスルールに同意し、予約する をタップします。定期的な予約は 繰り返し をオンに。

多くのお店は手動で予約を確定し、通知が届きます。自動で確定するお店もあります。

↑ トップへ戻る

4予約の確認

  • マイ予約 で予約をタップすると、カレンダーへの追加、経路の確認、お店への電話、オンラインミーティングへの参加ができます。
  • お店の無料キャンセル期限までは 日時を変更 やキャンセルができます。それ以降はお店に電話してください。直前キャンセルや無断キャンセルの料金は、予約前に必ず表示されます。
  • お支払いはお店に直接行います。Bestli が予約の代金を受け取ることはありません。
  • 前日の夕方にリマインダーが届き、来店後に評価できます。

事業者向け

1お店を設定する

  • 設定 で Bestliでサービス提供を始める をタップし、短い設定を進めます。
  • あとから 設定 → あなたのビジネス ですべて変更できます。
  • 新しいお店は最初の1か月が無料です。
↑ トップへ戻る

2サービスとパッケージ

  • 各サービスに名前・価格・所要時間、必要なら説明と写真を設定します。
  • サービス後の休憩は、清掃や準備のための時間を空けておきます。
  • 再予約リマインダーは、数週間後にお客様へ再来店を促します。
  • パッケージは、よく一緒に予約されるサービスをまとめます。
↑ トップへ戻る

3営業時間と休業日

  • 曜日ごとに1行。定休日はオフにします。昼休みがあれば追加します。
  • 特別営業時間 は特定の日付だけを変更します。通常は休みの日でも開けられます。
  • 休業日は期間（開始〜終了）で追加します。祝日を追加 で国の祝日を入力できます。
↑ トップへ戻る

4予約ルール

  • お客様が選べるスタッフや席を追加します。名前をタップすると、その人の勤務時間と休みを設定したり、本人のアカウントに招待したりできます。
  • 自動確定、Multibook（同じ時間に複数のお客様）、ハウスルールを設定します。
  • キャンセルでは、アプリでキャンセルできる期限と、任意で直前キャンセル／無断キャンセル料金を設定します。
↑ トップへ戻る

5予約を管理する

  • 新しいリクエストは通知とともに ダッシュボード と 予約 に表示されます。そこで確定または辞退します。
  • 来店後は完了または無断キャンセルにします。これは確定事項です。完了した予約は 売上 に加算されます。
  • 金額が違った場合は 支払額を編集 を使います。飛び込みや電話予約は + で追加します。
↑ トップへ戻る

6チーム

  • 予約ルール でスタッフをタップし、メールアドレスを入力して 招待を送信 をタップします。
  • 承諾後、スタッフは マイスケジュール で自分の予約と自分の 収入 だけを見られます。
  • 取り決めを設定：お店が支払う、手数料、月額レンタル。
  • 外されたメンバーは、データを書き出せるよう7日間閲覧できます。
↑ トップへ戻る

7お客様に届ける

  • 事業者情報を共有 や QRコードを表示、さらにカウンター用のポスターやカードも印刷できます。
  • 空き枠をお知らせ で、お店を保存したお客様に直前の空き枠を知らせます。
  • カレンダーで購読 で予約をスマートフォンのカレンダーに表示します。
↑ トップへ戻る

8売上

  • 日・週・月・年ごとに収入と支出を表示します。税と月間目標は 料金と税金 で設定します。
  • 会計用に CSV を書き出せます。データをエクスポート ですべてダウンロードできます。
↑ トップへ戻る

9サブスクリプション、休止、閉店

  • 無料期間のあとは サブスクリプションと請求 で登録します。お客様は Bestli を常に無料で使えます。
  • 予約を一時停止 で、休暇中などにお店を検索から非表示にできます。
  • ビジネスを削除 でお店を削除しても、アカウントは残ります。先にサブスクリプションを解約してください。
↑ トップへ戻る

  • または bestli.app.team@outlook.com までメールでどうぞ。すべてのメッセージに目を通しています。
